# 모션 · 다크모드 · 영어 지원

2026-11-01 · 기존 `frontend-design` 방향과 로켓, Pretendard, 앰버 문의 버튼을 유지했다.

## 적용

- 첫 화면의 글과 로켓 영역이 400–500ms 동안 한 번만 등장한다. 메뉴·개인정보 창과 FAQ에는 160ms의 짧은 반응을 적용했다. 자동 반복·스크롤마다 등장하는 효과는 추가하지 않았다. `prefers-reduced-motion`에서는 등장 애니메이션을 사용하지 않는다.
- 상단 달/해 버튼으로 라이트·다크 모드를 전환한다. 첫 방문은 기기 설정을 따르고, 직접 선택하면 `freak-theme` localStorage에 저장한다. 다른 탭의 변경도 동기화한다. 저장소가 차단돼도 현재 페이지의 전환은 동작한다.
- 배경·본문·서비스·폼·헤더·메뉴·개인정보 창의 색상을 의미별 CSS 변수로 관리한다. 다크모드는 푸른 잉크 계열 바탕과 밝은 본문으로 구성하고 앰버 버튼은 어두운 글자를 유지한다.
- 상단 `EN` / `한국어` 링크로 언어를 바꾼다. 한국어는 `/`, `/introduce`, 영어는 `/en`, `/en/introduce`에서 제공한다. 같은 언어의 페이지·문의 앵커로 이어지는 링크를 사용하므로 탐색·새로고침에도 선택이 유지된다.
- 본문, 서비스 설명, FAQ, 후기, 폼·접근성 레이블, 개인정보 안내, 전송 실패·성공 메시지까지 영문을 제공한다. 기존 한국어 내용의 번역이며 기존 수치·후기의 사실 검증은 이번 범위가 아니다.
- 언어별 문서의 `html lang`, 제목·설명, Open Graph locale, 언어 대체 링크를 서버에서 생성한다. 영어 콘텐츠는 JavaScript가 없어도 서버 HTML에 있다.

## 구조

`frontend/app/(korean)`은 기존 한국어 주소를 유지하고 `frontend/app/en`은 영어 주소를 제공한다. 두 언어의 루트는 공통 `frontend/app/RootDocument.tsx`를 사용한다. 홈·회사소개 구현은 `frontend/components/pages/`에서 공유한다.

번역은 `frontend/lib/messages.en.json`, 언어 링크는 `frontend/components/LocalizedLink.tsx`, 테마 저장·기기 설정은 `frontend/lib/theme.ts`에서 관리한다. 언어가 다른 루트로 전환할 때는 Next.js의 문서 전체 탐색을 사용하며 테마는 저장된 선택으로 초기화된다.

## 실제 검증

- [빌드](build.txt): 프로덕션 빌드와 TypeScript 검사 통과. 4개 언어별 페이지가 정적으로 생성된다.
- [린트](lint.txt): 오류·경고 0개.
- [화면 검사](layout-checks.json): 4개 경로 × 2개 테마 × 4개 너비(1440 / 1024 / 390 / 320), 총 32개 조합에서 가로 넘침 없음. 언어·테마가 기대값과 일치하고 H1 하나, 영문 화면의 예상하지 않은 한글 노출 없음, hydration·런타임 오류 없음.
- 같은 검사에서 데스크톱·모바일, 두 언어·두 테마의 axe-core WCAG 2 A/AA 및 2.1 A/AA 자동 검사 16개 조합 위반 0건. 자동 검사 결과는 전체 접근성 적합 인증이 아니다.
- [동작 검사](interaction-checks.json): 테마 저장·새로고침·언어 이동·새 탭·다른 탭 동기화, 영문 메뉴·회사소개·FAQ·수동 후기·문의 앵커, 영문 개인정보 창·Escape·포커스 복귀, 영문 전송 실패·성공 표시, 모션 감소 설정, JavaScript 없는 영어 HTML 검증.
- [테마 경계 조건](theme-edge-checks.json): hydration 스크립트를 차단해도 head 스크립트가 다크모드를 초기화함. localStorage 차단 시 정상 동작. 기기 설정 변경 추적과 수동 선택 우선순위 확인.
- [다크모드 대화상자](dark-dialog-checks.json): 한국어·영어 모바일 메뉴 및 개인정보 창의 접근성 자동 검사 위반 0건.
- 영문 라이트 데스크톱·다크 모바일과 영문 다크 대화상자 캡처를 직접 검토했다. 언어 버튼은 보이는 이름과 접근성 이름을 맞추고 작은 화면의 설정 버튼 간격을 조정했다.

## 범위

실제 기기·Safari·Firefox·Lighthouse 검사는 수행하지 않았다. 문의 API는 기존 연동 상태이며 전송 검증에는 모의 응답만 사용했다. 실제 문의는 전송하지 않았다. 새 npm 의존성을 추가하지 않았다.
