# Frontend design 적용 결과

2026-11-01 · 홈, 회사소개, 공유 헤더·푸터

## 변경

- 기존 브랜드 문구와 Pretendard, 앰버 문의 버튼을 유지하고 밝은 제작실 분위기로 통일했다. 원본 로켓이 첫 화면의 중심이며 도면 격자와 아이디어→서비스 구성을 사용한다.
- 장식용 영문 올캡스 문구, 임의 서비스 번호, 단어 일부만 색칠한 제목을 제거했다. 자동 애니메이션은 추가하지 않았다.
- 홈을 서비스 목록→협업 원칙→실제 3단계 진행 과정→FAQ→문의 순서로 정리했다. 번호는 실제 진행 단계에만 사용한다.
- 문의 폼의 label, 자동완성, 동의 창, 실패·성공 상태 및 입력값 보존을 유지하면서 데스크톱에서 설명과 폼을 나란히 배치했다.
- 회사소개에도 같은 색상과 제목 체계를 적용하고, 반복 임시 이미지를 제거했다. H1을 추가하고 동작하지 않던 하단 상담 버튼을 실제 문의 링크로 바꿨다. FAQ 열림 상태와 숨김 상태를 접근성 속성으로 연결했다.
- 원본 로켓을 맨 위로 버튼에도 적용했다. npm 의존성, 서버 연동, 배포 설정은 변경하지 않았다.

디자인 계획과 자체 검토: [DESIGN.md](DESIGN.md)

## 실제 검증

- [빌드 로그](build.txt): Next.js 프로덕션 빌드와 TypeScript 검사 통과.
- [린트 로그](lint.txt): 오류 0개, 경고 0개.
- [홈 브라우저 검사](browser-checks.json): 1440 / 768 / 390 / 320px에서 가로 넘침·빈 링크·누락 앵커·런타임 오류 없음. 모바일 메뉴 포커스·Escape·스크롤 해제, FAQ, 개인정보 창, 문의 성공·실패 모의 응답 검증.
- [회사소개 브라우저 검사](company-checks.json): 1440 / 1024 / 768 / 390 / 320px에서 문서 가로 넘침·런타임 오류 없음, H1 하나 확인.
- axe-core WCAG 2 A/AA, 2.1 A/AA 태그 검사: 홈과 회사소개의 데스크톱·모바일 및 홈의 대화상자에서 자동 위반 0건. 수동 확인이 필요한 incomplete 항목은 남아 있어 전체 접근성 적합 인증을 뜻하지 않는다.
- [추가 동작 검사](company-actions.json): 회사소개 FAQ 열림·숨김, 하단 실제 문의 링크, 로켓 맨 위로 버튼 확인.
- 홈 데스크톱 첫 화면 및 모바일 전체 화면, 회사소개 모바일 전체 화면을 직접 검토하고 장식과 반복 미디어를 덜어냈다.

## 남은 범위

실제 `/api/contact.php`는 로컬 404 상태로, 문의 검증은 모의 응답을 사용한 UI 검증이다. 실제 접수 서버 연결과 수신 확인은 별도 작업이 필요하다. 기존 회사소개 실적·후기 수치는 이번 작업에서 새로 만들거나 검증하지 않았다. 실제 기기, Safari·Firefox, Lighthouse 검사는 수행하지 않았다. 모든 디자인·브라우저 작업은 로컬에서 진행했다.
